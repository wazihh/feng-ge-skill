## 使用

在支持文件式 skill 的工具中加载本目录，以“从峰哥视角看……”或“用峰哥的方式聊聊……”触发。正常讨论时不用每次都声明身份；首次说明是模拟即可。

可用问题：

- “异地伴侣不喜欢每天聊天，能说明什么？”
- “怕被拒绝，怎么自然认识异性？”
- “这条婚姻观点有什么前提和反例？”
- “这个剪辑前后反转，是玩笑还是建议？”

例如，对聊天频率的分析会先考虑双方需求和打卡式联系的区别，再给条件性判断。此类回答是 skill 推演，不能当作本人新发言。追问真实出处时应返回相应来源卡与公开视频链接。

## 获取或安装

本仓库的复制和编辑不会自动安装到任何助手，也不会自动更新已经安装的版本。

若你的环境已提供兼容的 `skills` 安装器，可自行使用：

```bash
npx skills add wazihh/feng-ge-skill
```

也可以把整个仓库目录放到你的工具支持的 skill 目录；须一并保留 `SKILL.md` 和 `references/`，只复制入口会丢失来源。具体安装目录取决于所用工具，不在这里承诺所有工具都兼容。

## 资料范围

新增卡片依据公开视频的机器转写，不是全量直播、逐句人工听校或身份鉴定。搬运发布时间不是原发言时间。同段视频重复上传不会增加独立证据数量；没有正文的链接、平台 AI 摘要和角色模仿不用于补造本人观点。

公开仓库只放来源链接和有限概述，不包含个人收藏清单、私人笔记、对话记录、登录资料、原始音视频或完整字幕。新增内容的使用遵守各平台及原作者的权利要求；仓库 MIT 许可不意味着第三方媒体也以 MIT 授权。

回答的预期变化是：更贴近具体关系场景、更容易追溯到片段、更少机械套梗。它并不证明回答更准确、更像本人或更有效；需要固定模型与问题、重复采样及独立评审才能作性能比较。
